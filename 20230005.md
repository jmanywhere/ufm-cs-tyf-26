En este laboratorio aprendí que una firma digital permite demostrar que una persona controla una clave privada sin necesidad de revelarla. La clave privada se utiliza para firmar un mensaje, mientras que la clave pública y la dirección Ethereum permiten comprobar quién produjo la firma.

# lab 2
https://jtanchezz.github.io/Tech-Freedom-Lab2/ 
En este laboratorio aprendí que una frase semilla puede utilizarse para generar múltiples cuentas Ethereum. No es necesario crear y guardar una frase diferente para cada dirección, ya que todas pueden derivarse de una única semilla mediante un sistema jerárquico determinístico.

# lab 4
https://jtanchezz.github.io/Tech-Freedom-Lab4/ 
Aprendí a crear dos billeteras de Bitcoin Testnet usando Tether WDK. También aprendí a enviar fondos de prueba desde una billetera de origen hacia otra de destino. Entendí que Bitcoin utiliza UTXOs para representar los fondos disponibles. Cuando se realiza un pago, el dinero sobrante regresa a la billetera de origen como cambio. Esta práctica me permitió conocer cómo funciona una transacción de Bitcoin sin utilizar dinero real.
